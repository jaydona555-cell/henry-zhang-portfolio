# Henry Zhang — Portfolio

Personal portfolio website for **Henry Zhang (Haitao Zhang)**, Senior IT Specialist & Backend Systems Architect with 15+ years of experience in cloud, AI, and IoT systems.

## Live site

🌐 https://henry-zhang-portfolio.vercel.app

## Stack

Plain HTML, CSS, and vanilla JavaScript — no build step, no framework, no dependencies.

- `index.html` — single-page layout: hero, about, experience, projects, skills, contact
- `styles.css` — modern professional design with dark/light theme
- `script.js` — theme toggle, mobile nav, scroll animations
- `assets/` — profile photo

## Deploy

Any static host works. Currently deployed on **Vercel**, connected to this repo — every push to `main` auto-deploys.

```bash
# Preview locally
npx serve .
```
